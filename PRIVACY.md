# Política de Privacidad

**Última actualización: 16 de noviembre de 2026**

Monster Index DB no recopila, almacena ni comparte datos personales. La
aplicación no utiliza SDKs de rastreo ni servicios de analítica de terceros.

Para mostrar la información solicitada, la aplicación realiza consultas HTTPS a
PokéAPI (`pokeapi.co`). También carga imágenes y sonidos desde las direcciones
incluidas en las respuestas de PokéAPI. Estas solicitudes sirven únicamente
para presentar el contenido de la aplicación.

La aplicación no cuenta con cuentas de usuario, publicidad ni formularios para
enviar información personal.
